## Known operational gaps

1. There is no custom IP/device fingerprint fraud system.
2. There is no direct Easypaisa/JazzCash/bank API integration.
3. The application cannot independently verify an ordinary advertising click as a rewardable event.
4. Support contact configuration is still required before production launch.
5. Supabase Auth rate limits and Cloudflare WAF/rate limits must be configured for production.
